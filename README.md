## How I work

- **Build, check and improve.** I use AI-assisted development to move quickly, then review the code and verify outputs through tests, evaluation and failure analysis.
- **Keep evidence close to the result.** I document data sources, assumptions, measured outcomes and limitations. Local demonstrations and synthetic tests are distinguished from cloud operation and real-user studies.
- **Listen and follow through.** I enjoy completing useful tools, welcome feedback and correct mistakes promptly, adding checks to reduce recurrence.
- **Treat data carefully.** I consider access controls, confidentiality, source traceability and human approval when designing workflows.
